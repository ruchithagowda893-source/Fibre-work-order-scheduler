# Fibre Installation Work-Order Scheduling Engine

## Project Description
A scheduling system that assigns fibre installation work orders to available technicians based on their skills, work zones, availability and workload.

## Main Objectives
1. Manage technician information.
2. Manage fibre installation work orders.
3. Identify technician availability.
4. Assign suitable technicians to work orders.
5. Generate an optimized work schedule.
6. Export the final schedule as a CSV report.

## Technologies
- Python
- CSV
- Data Structures
- Scheduling Algorithms

## Project Structure
- data: Input datasets
- src: Python source code
- tests: Testing files
- outputs: Generated reports
